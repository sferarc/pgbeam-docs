          autocomplete and view-aware warnings in the policy editor — relation
          kind distinguishes a view (whose masking/row-filters apply to the view
          itself, not its base tables) from a base table, and a per-column
          is_binary flag flags columns that mask to NULL. System schemas are
          excluded; nothing is persisted.
