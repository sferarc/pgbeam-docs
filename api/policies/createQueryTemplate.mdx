      - content: >
          Adds a named, parameterized statement to the project. A template admits
          
          a statement for a policy profile that runs templates only; it never
          
          grants access, and the statement still meets the credential's whole
          
          policy.
          
          
          The SQL is parsed and checked when it is written: exactly one SELECT,
          
          INSERT, UPDATE or DELETE, placeholders $1 to $n, one declared parameter
          
          for each. A template that fails is refused with 400 and a message
          
          naming the problem. Returns 409 when the project already has a template
          
          of that name.
          
          
          The template is pushed to connected data planes when it is written.
          
          
          Returns 409 for an enabled template while the organization has a live
          
          self-hosted data plane enrollment, because PgBeam cannot yet confirm
          
          that a self-hosted proxy runs a build that enforces templates. A
          
          template with enabled set to false is still accepted.
