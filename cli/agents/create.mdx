Issue a scoped Postgres login and hosted MCP token for an AI agent. The connection string and MCP token are shown once and cannot be retrieved again. Store them securely.

## Usage

```bash
pgbeam agents create [flags]
```

## Options

| Option | Description | Required | Default |
| ------ | ----------- | -------- | ------- |
| `--name <value>` | Human-readable label for the credential | Yes | - |
| `--policy <value>` | Policy profile ID to enforce | Yes | - |

<Callout type="info" title="Global options">
All [global options](/docs/cli/global-options) (`--token`, `--profile`, `--project`, `--org`, `--json`, `--no-color`, `--debug`) are also available on this command.
</Callout>

## Examples

```bash
# Create a credential bound to a policy profile
pgbeam agents create --name "Claude Code" --policy pol_xxx

# Create and capture secrets as JSON
pgbeam agents create --name ci --policy pol_xxx --json
```

## Output

Prints the connection string, MCP URL, and MCP token once. With --json, returns the full secrets object.
