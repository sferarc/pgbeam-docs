Permanently revoke an agent credential. Any live connections using it are dropped within seconds. This cannot be undone.

## Usage

```bash
pgbeam agents revoke <id>
```

## Options

| Option | Description | Required | Default |
| ------ | ----------- | -------- | ------- |
| `<id>` | Agent credential ID | Yes | - |

<Callout type="info" title="Global options">
All [global options](/docs/cli/global-options) (`--token`, `--profile`, `--project`, `--org`, `--json`, `--no-color`, `--debug`) are also available on this command.
</Callout>

## Examples

```bash
# Revoke a credential
pgbeam agents revoke agt_xxx
```

## Output

Confirms the credential was revoked.
