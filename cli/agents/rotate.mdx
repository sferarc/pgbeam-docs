Generate a new Postgres password and MCP token for an existing credential, keeping its id, username, name, and policy. Connections using the old password are dropped within seconds. The new secrets are shown once and cannot be retrieved again — update your agent before its next call.

## Usage

```bash
pgbeam agents rotate <id>
```

## Options

| Option | Description         | Required | Default |
| ------ | ------------------- | -------- | ------- |
| `<id>` | Agent credential ID | Yes      | -       |

<Callout type="info" title="Global options">
  All [global options](/docs/cli/global-options) (`--token`, `--profile`,
  `--project`, `--org`, `--json`, `--no-color`, `--debug`) are also available on
  this command.
</Callout>

## Examples

```bash
# Rotate a credential's secrets
pgbeam agents rotate agt_xxx

# Rotate and capture secrets as JSON
pgbeam agents rotate agt_xxx --json
```

## Output

Prints the new connection string, MCP URL, and MCP token once. With --json, returns the full secrets object.
