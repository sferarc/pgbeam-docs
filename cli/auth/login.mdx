Authenticate with PgBeam to access your projects and databases. Login uses an API key, which you generate from the PgBeam dashboard; running the command prompts you to paste it. Credentials are stored in a local profile on disk (`~/.config/pgbeam/`). You can maintain multiple profiles for different environments using the `--profile` flag.

## Usage

```bash
pgbeam auth login [flags]
```

## Options

| Option      | Description                                                | Required | Default |
| ----------- | ---------------------------------------------------------- | -------- | ------- |
| `--api-key` | Authenticate with an API key (the default and only method) | No       | `false` |

<Callout type="info" title="Global options">
  All [global options](/docs/cli/global-options) (`--token`, `--profile`,
  `--project`, `--org`, `--json`, `--no-color`, `--no-trunc`, `--debug`) are
  also available on this command.
</Callout>

## Examples

```bash
# Login with an API key (prompts for the key)
pgbeam auth login

# Login with an API key and save to a named profile
pgbeam auth login --profile production
```

## Output

On success, prints a confirmation message with the authenticated profile name. The token is stored locally and used for all subsequent commands.
