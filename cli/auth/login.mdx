Authenticate with PgBeam to access your projects and databases. Login uses an API key, which you generate from the PgBeam dashboard. Run with `--api-key` to go straight to the key prompt, or run without flags for an interactive prompt. Credentials are stored in a local profile on disk (`~/.config/pgbeam/`). You can maintain multiple profiles for different environments using the `--profile` flag. Browser-based login is not available yet.

## Usage

```bash
pgbeam auth login [flags]
```

## Options

| Option      | Description                                                                                                                                               | Required | Default |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ------- |
| `--api-key` | Authenticate with an API key. You will be prompted to paste a key generated from the PgBeam dashboard. This is currently the only supported login method. | No       | `false` |

<Callout type="info" title="Global options">
  All [global options](/docs/cli/global-options) (`--token`, `--profile`,
  `--project`, `--org`, `--json`, `--no-color`, `--debug`) are also available on
  this command.
</Callout>

## Examples

```bash
# Interactive login (prompts for method)
pgbeam auth login

# Login directly with an API key
pgbeam auth login --api-key

# Login with an API key and save to a named profile
pgbeam auth login --api-key --profile production
```

## Output

On success, prints a confirmation message with the authenticated profile name. The token is stored locally and used for all subsequent commands.
