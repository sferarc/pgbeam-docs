Show the full configuration of a policy profile: access mode, statement rules, table allow/deny lists, masking rules, budgets, and limits.

## Usage

```bash

```

## Options

| Option | Description       | Required | Default |
| ------ | ----------------- | -------- | ------- |
| `<id>` | Policy profile ID | Yes      | -       |
