Retunes one detection metric for this project, or for one agent credential in it. Without a rule every metric resolves to the deployment default.

A rule adds no detection algorithm and no alert kind: it changes how sensitive one of the five existing metrics is. enabled=false silences that metric for that scope; the baseline keeps advancing, so re-enabling resumes from the existing history rather than a cold warm-up.

## Usage

```go
result, err := client.Anomalies.CreateAnomalyRule(ctx, "prj_xxx", pgbeam.AnomalyRuleInput{
    Metric: pgbeam.AnomalyMetric{ /* ... */ },
  })
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| ctx | `context.Context` | Yes | Request context |
| projectID | `string` | Yes | Unique project identifier (prefixed, e.g. prj_xxx). |
| req | `pgbeam.AnomalyRuleInput` | Yes | Request body |
| req.CredentialID | `*string` | No | Agent credential to scope the rule to. Null or omitted applies it to every credential in the project. The credential must belong to this project. |
| req.Metric | `pgbeam.AnomalyMetric` | Yes | One of the five detection metrics. A rule retunes how sensitive one of them is; it adds no detection algorithm and no alert kind. |
| req.SigmaThreshold | `*float64` | No | N in the "mean + N \* dispersion" spike rule. Must be greater than zero; the detector reads any value at or below zero as "use the default", so a stored zero could never mean what setting it would suggest. Rejected for distinct_shapes and active_hours, which have no rate for sigma to put a threshold on. Null or omitted leaves the deployment default in place. |
| req.Floor | `*float64` | No | Absolute floor below which the metric never alerts. Must be greater than zero, for the same reason as sigma_threshold. Rejected for distinct_shapes and active_hours, which have no rate for a floor to bound. Null or omitted leaves the deployment default in place. |
| req.Enabled | `*bool` | No | False silences this metric for this scope. The baseline keeps advancing while it is silenced, so re-enabling resumes from the existing history rather than a cold warm-up. |

## Response

`(*pgbeam.AnomalyRule, error)`: anomaly rule created.
