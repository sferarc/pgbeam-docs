Returns agent statement audit entries for the project, newest first, with
optional credential and event filters.

## Usage

```typescript

  pathParams: { project_id: "prj_xxx" },
});
```

## Parameters

| Parameter                 | Type     | Required | Description                                                 |
| ------------------------- | -------- | -------- | ----------------------------------------------------------- |
| pathParams.project_id     | `string` | Yes      | Unique project identifier (prefixed, e.g. prj_xxx).         |
| queryParams.credential_id | `string` | No       | Filter to a single agent credential.                        |
| queryParams.event         | `string` | No       | Filter to a single event type (e.g. blocked).               |
| queryParams.before        | `string` | No       | Return entries strictly older than this timestamp (cursor). |
| queryParams.page_size     | `number` | No       | Maximum number of items to return (1-100, default 20).      |
