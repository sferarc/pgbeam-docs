Adds a task to the CRM research queue. The autonomous research worker leases pending tasks, enriches the subject entity, and writes results back.

## Usage

```typescript
const result = await api.crm.createCrmResearchTask({
    pathParams: { org_id: "org_abc123" },
    body: {
      kind: { ... },
      subject_type: { ... },
      subject_id: "...",
    },
  });
```

| Parameter         | Type                      | Required | Description                                       |
| ----------------- | ------------------------- | -------- | ------------------------------------------------- |
| pathParams.org_id | `string`                  | Yes      | Unique organization identifier.                   |
| body.kind         | `ResearchTaskKind`        | Yes      |                                                   |
| body.subject_type | `ResearchTaskSubjectType` | Yes      |                                                   |
| body.subject_id   | `string`                  | Yes      | ID of the company/contact/deal this task targets. |
| body.role         | `AgentRole`               | No       |                                                   |
| body.priority     | `number`                  | No       | Higher runs first.                                |
