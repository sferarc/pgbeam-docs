Adds a named, parameterized statement to the project. A template admits a statement for a policy profile that runs templates only; it never grants access, and the statement still meets the credential's whole policy.

The SQL is parsed and checked when it is written: exactly one SELECT, INSERT, UPDATE or DELETE, placeholders $1 to $n, one declared parameter for each. A template that fails is refused with 400 and a message naming the problem. Returns 409 when the project already has a template of that name.

The template is pushed to connected data planes when it is written.

Returns 409 for an enabled template while the organization has a live self-hosted data plane enrollment, because PgBeam cannot yet confirm that a self-hosted proxy runs a build that enforces templates. A template with enabled set to false is still accepted.

## Usage

```typescript
const result = await api.policies.createQueryTemplate({
  pathParams: { project_id: "prj_xxx" },
  body: {
    name: "open_orders_for_customer",
    sql: "SELECT id, total FROM orders WHERE customer_id = $1 AND status = 'open' ORDER BY created_at DESC",
  },
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| pathParams.project_id | `string` | Yes | Unique project identifier (prefixed, e.g. prj_xxx). |
| body.name | `string` | Yes | Name an agent invokes the template by. A lower-case identifier starting with a letter, at most 63 characters, unique within the project. |
| body.description | `string` | No | What the template is for, shown to an agent that lists the templates. |
| body.sql | `string` | Yes | The statement, with its parameters as $1, $2 and so on. Exactly one SELECT, INSERT, UPDATE or DELETE, at most 16384 bytes. Every placeholder must be declared in params and every declared parameter must be used. |
| body.params | `QueryTemplateParam[]` | No | Declared parameters, in placeholder order. Omitted means none. |
| body.include_sql | `boolean` | No | True shows the SQL text to an agent that lists the templates. Defaults to false, since a WHERE clause can itself be sensitive. |
| body.enabled | `boolean` | No | Defaults to true, so a template is admitted as soon as it is written. False saves it withdrawn. |

## Response

`Promise<QueryTemplate>`: query template created.
