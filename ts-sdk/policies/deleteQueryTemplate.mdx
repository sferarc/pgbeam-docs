Removes the template, so a profile that runs templates only stops admitting its statement. Deleting the last template is allowed: such a profile then admits nothing, which is the intended way to withdraw access in an incident.

## Usage

```typescript
const result = await api.policies.deleteQueryTemplate({
  pathParams: { project_id: "prj_xxx", query_template_id: "qtp_xxx" },
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| pathParams.project_id | `string` | Yes | Unique project identifier (prefixed, e.g. prj_xxx). |
| pathParams.query_template_id | `string` | Yes | Unique query template identifier (prefixed, e.g. qtp_xxx). |

## Response

`Promise<void>`: no content.
